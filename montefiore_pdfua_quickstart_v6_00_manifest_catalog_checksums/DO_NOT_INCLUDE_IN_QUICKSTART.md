# Do Not Include in Quickstart Packages

Do not include:

- qpdf binaries or source trees.
- veraPDF installers or binaries.
- Active source PDFs.
- Remediated PDFs from previous jobs.
- Previous diagnostic packages.
- Patch-overlay duplicates.
- Temporary render folders.
- Old top-level v4/v5 folders competing for control.
- Local machine paths.
- Credentials or API tokens.
- Font files.
